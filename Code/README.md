# Code

This folder is intentionally empty for now.

R.O.B.B.Y.'s V1 build is hardware-first — CAD and mechanical design are being 
finalized before any voice/servo control code is written. Development here will 
begin once the base is fabricated and wiring is in place.

Planned scope for V1 code:
- Voice command capture (ReSpeaker mic array)
- Command parsing / intent matching
- Servo control logic (Raspberry Pi Zero 2W → MG90S/MG92B)
- Basic orchestration tying voice input to physical movement
